# House rules for this folder

Everything in this folder is dummy data made for a workshop. Treat it as if it were real.

- Work only inside this folder. Don't read or write anywhere else.
- The CSV files you were given are originals. Never edit them; write new files next to them.
- Before you run any code, explain in plain English what it will do.
- Put exact checks (duplicates, blanks, formats, dates) in code. Use your own judgment only where I ask
  for it, and say which is which.
- When a row doesn't fit the rules, mark it "needs review" with a reason. Don't guess.
- Never send email, post, or upload anything.
